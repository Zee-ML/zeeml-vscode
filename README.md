## Included Editor Commands (`Ctrl+Shift+P`) & Live Status Bar

1. **Live Status Bar Telemetry (`ZeeML: <words>w | CV <burstiness>`):** Automatically computes word count and sentence-length coefficient of variation as you edit or select text.
2. **`ZeeML: Flatten Selection JSON to RFC-4180 CSV`:** Converts deeply nested JSON objects or arrays into an RFC-4180 CSV document with formula-injection protection.
3. **`ZeeML: Parse Selection RFC-4180 CSV to JSON`:** Converts quoted RFC-4180 CSV rows back into structured JSON objects.
4. **`ZeeML: Convert Selection JSON to Aligned Markdown Table`:** Generates GitHub-Flavored Markdown tables from JSON records.
5. **`ZeeML: Convert 10-Point CGPA to Percentage & 4.0 GPA`:** Instant CBSE/UGC 9.5x, Direct 10x, and AICTE conversion popup.
